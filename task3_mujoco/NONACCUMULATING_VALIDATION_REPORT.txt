NON-ACCUMULATING TARGET CONTROL VALIDATION
==========================================

Controller changes
------------------
1. FR3 arms remain position controlled.
2. IK qdot is converted to a bounded target relative to measured q:
       q_ref = q_measured + qdot * 0.030 s
3. The spine remains dynamically position actuated.
4. Spine target is relative to measured height:
       z_ref = z_measured + command * 0.18 m/s * 0.100 s
5. Wall-clock loop duration is not integrated into the spine target.
6. Releasing the spine key resets z_ref to the measured height.
